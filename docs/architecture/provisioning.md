# Provisioning summary

> **Document status:** Confirmed Target V1 contract.

CompanyHQ is provisioned from a local CLI onto a remote server. Each command creates or reconciles one independent company installation; it never registers the company with a central service. The detailed contracts are in [provisioning overview](../provisioning/overview.md), [CLI](../provisioning/cli.md), and [company installation](../provisioning/company-installation.md).
