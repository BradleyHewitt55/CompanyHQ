# MCP prompts

> **Document status:** Target V1 registry contract.

Prompts are versioned, reviewed templates with stable IDs, owner, purpose, input schema, applicable company/role/task scopes, required resources/tools, delivery format, injection boundaries, and audit event. Registration conflicts fail configuration compilation.

Prompt delivery inserts current authorized context server-side. Templates cannot grant tools, choose another installation, expose hidden data, or override policies. Changes create a new version; runs record the exact version/hash.
