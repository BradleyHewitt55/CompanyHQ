# Review flow

> **Document status:** Target V1 product contract.

Review presents objective, acceptance criteria, scope, effective permissions, plan, changed files/content commands, unified diff, checkpoints, test evidence, security/policy changes, costs, warnings, and unresolved questions. Reviewers can request changes, reject, cancel, approve a next action, or mark task complete.

Commit, push, pull-request creation, merge, deployment, schema migration, and publication are separate actions. No approval is reusable after the diff, resource version, policy, or target changes. Agents can never review/approve/merge their own or another agent's protected change.
